# ADR-0011: Skill intelligence

**Status:** accepted (2026-10-17)

The snapshot has no descriptions. Card tags are truncated: 1,127 of 1,133 jobs carry a
"+N" marker, and only 1,196 of 6,899 tags (17%) are visible. "Hybrid" and "Remote" were
mixed into the same field.

**Decision:** do not publish skill-demand rankings. The skills page shows *visible tag*
frequencies with the denominator and the truncation statistics, and explains what is
missing. Work-arrangement tags are moved to `work_arrangement`. A versioned bilingual
skill dictionary with rule-based extraction, evaluated on a manually reviewed sample, is
the planned baseline once a permitted source provides descriptions.
